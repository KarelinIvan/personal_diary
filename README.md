# Personal Diary — Личный дневник

Проект представляет собой веб-приложение на Django с простым интерфейсом пользователя. Позволяет вести личный блог: создавать статьи, редактировать их, удалять и искать по содержимому. Доступ к записям ограничен только автором.

## 📌 Основные функции:
- CRUD для статей: создание, просмотр, изменение, удаление записей в личном блоге.
- Поиск: реализация поиска по заголовку или содержанию статьи через `Q` объекты Django ORM.
- Авторизация: регистрация пользователей с подтверждением email и авторизация.
- Изоляция данных: пользователи видят только свои записи благодаря фильтрации в методах `get_queryset`.
- Пагинация: вывод 5 записей на страницу для удобства чтения.

## 🛠 Технологии и стек:
- Backend: Python 3.12+, Django 5.1+
- Шаблонизатор: Django Templates
- База данных: PostgreSQL
- Валидация форм: встроенные механизмы Django
- Развертывание: Docker, Docker Compose
- Документация: отсутствует (API не реализовано), но структура приложения описана в этом файле.

## 🚀 Запуск проекта

### Вариант A: Через Docker (рекомендуется)
Скопируйте файл `.env.example`, заполните его секретными ключами и выполните:

Создайте виртуальное окружение:
python -m venv venv

Установите зависимости:
pip install -r requirements.txt

Примените миграции базы данных:
python manage.py migrate

Создайте суперюзера для доступа к админке:
python manage.py createsuperuser

Запустите сервер разработки:
python manage.py runserver

После запуска откройте браузер по адресу [http://127.0.0.1:8000](http://127.0.0.1:8000). 
Для входа используйте данные созданного суперпользователя.
